# An-lisis-de-Riesgo-Crediticio-con-ML
Proyecto de Finanzas Cuantitativas para predecir el incumplimiento bancario. Implementación de Random Forest con un 98% de Recall mediante técnicas de Undersampling y validación cruzada de 5 particiones. Cubre curación avanzada, EDA técnico y evaluación de métricas de negocio.
